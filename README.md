# Modern Roof Landing Page

A responsive landing page developed for a modern roofing company. The project focuses on creating a clean user experience, responsive layout, and SEO-friendly structure using only HTML, CSS, and vanilla JavaScript without any external framework.

## Live Demo

🚀 https://test-app.dgrex.io/



---

## Features

### Semantic HTML

The page is built using semantic HTML5 elements such as `<header>`, `<main>`, `<section>`, `<article>`, and `<footer>` to improve accessibility, readability, and search engine optimization.

### Responsive Design

The layout adapts to desktop, tablet, and mobile devices using CSS Grid, Flexbox, media queries, and fluid sizing with the `clamp()` function.

### Interactive Navigation

The navigation bar changes appearance when the page is scrolled. On smaller screens, the desktop navigation is replaced with a slide-in mobile menu controlled by JavaScript.

### Animated Statistics

The statistics section uses the Intersection Observer API to trigger a counting animation only when the section enters the viewport, improving both user experience and performance.

### Contact Form

The contact form includes basic client-side validation using JavaScript before allowing submission.

### SEO Optimization

The project includes meta descriptions, Open Graph tags, Twitter Card metadata, sitemap.xml, robots.txt, canonical URL, and optimized image assets to improve search engine visibility and social media sharing.

## Development Process

The project was completed incrementally through several development stages.

### 1. Semantic HTML Structure

Created the initial page structure using semantic HTML elements to establish a clean and accessible foundation before styling.

### 2. Global Styling

Implemented CSS variables, typography, spacing, reusable button styles, and a responsive navigation layout.

### 3. Hero & About Section

Developed the hero banner with a full-screen background image and call-to-action buttons, followed by the About section featuring company information and animated statistics.

### 4. Benefits & CTA Section

Designed a responsive benefit card grid and a call-to-action section to encourage users to contact the company.

### 5. Contact & Footer

Built the contact form and footer while maintaining consistent spacing, typography, and responsive behavior.

### 6. JavaScript Interactions

Added interactive features including:

- Sticky header
- Active navigation highlighting
- Mobile navigation menu
- Animated statistic counters
- Contact form validation

### 7. SEO & Performance

Optimized metadata, images, loading behavior, and search engine configuration to improve discoverability and performance.

### 8. Production Deployment

The final version was deployed to a production server and verified to ensure all assets, navigation, and SEO configuration worked correctly.
